# 🎮 Game Arena

A 4-page fully animated, responsive website for **Game Arena** — built with **HTML & CSS only**.

## Pages

| Page | Theme | Description |
|------|-------|-------------|
| `index.html` | 🌌 Dark Neon / Cyberpunk | Hero page with glitch logo, orbit rings, starfield, game cards |
| `action.html` | 🔥 Fire & Lava | Action games with flame effects, racing car, bullet trails |
| `puzzle.html` | 🌿 Enchanted Forest | Puzzle & adventure with fireflies, falling leaves, platformer |
| `feedback.html` | 🚀 Galaxy / Deep Space | Feedback form with rotating planet, shooting stars, star rating |

## Features

- ✅ Pure HTML + CSS (no frameworks)
- ✅ Fully responsive (mobile, tablet, desktop)
- ✅ Glassmorphism navigation bar
- ✅ Page-specific animated backgrounds
- ✅ CSS-only character & game animations
- ✅ Interactive feedback form with validation
- ✅ Star rating system (CSS-only)
- ✅ Toast notification on form submit

## Run Locally

Simply open `index.html` in any modern browser — no build step needed.
